## 📝 Descripción
Ejercicio práctico para conectar **Python** con **MySQL** usando `pymysql`.  
Simula un sistema CRUD básico (Crear, Leer, Actualizar, Eliminar) para gestionar productos de una tienda.

---

## ⚙️ Funcionalidades
- ✅ Agregar un producto.
- ✅ Agregar varios productos a la vez.
- ✅ Listar todos los productos.
- ✅ Consultar producto por código.
- ✅ Actualizar datos de un producto.
- ✅ Eliminar un producto.
- 🛡️ Manejo de errores con `try/except`.
